# RuaCLI

Version 1.0.0. Portable Windows x64 command-line access to RuaPDF, RuaFind, RuaImage and RuaHelper.

See README.ko.md for setup, commands, JSON output, tests and build instructions. Run `RuaCLI.exe tools` to discover 17 operations. Run `RuaCLI.exe licenses` for embedded notices.
