# Changelog

## 1.0.0 — 2026-10-27

- Initial Windows x64 portable CLI release.
- Reuses nine RuaMCP saved-file tools and exposes eight RuaHelper control tools.
- Adds readable subcommands, schema discovery, JSON arguments/files, JSON results and exit codes.
- Supports aspect-preserving image resize when one dimension is supplied.
- Preserves allowed-folder, no-overwrite and existing Helper permission/stop behavior.
- Includes embedded legal notices and corresponding source.
