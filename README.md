# RuaDay programs

Official versioned source distribution for RuaPDF, RuaFind, RuaImage and RuaHelper.

Downloads: https://ruaday.com/

Each release provides the corresponding application source, build instructions, license notices, file hashes and any required third-party source archives. Select the release matching the version of the executable. Source downloads are available without payment or a separate access request.

## Licenses

- RuaPDF: AGPL-3.0-or-later. Third-party licenses and corresponding source are included with its release.
- RuaImage: AGPL-3.0-or-later. Optional engine and model notices are included with its release.
- RuaFind: the application license is in its source archive; .NET/WPF and other third-party notices retain their original licenses.
- RuaHelper: original application copyright (c) 2026 yg; third-party .NET/WPF notices are included.

No single repository-wide license replaces individual component licenses. Follow the license and build instructions supplied with the chosen application and version.

Release source archives contain editable application code, artwork and build inputs. Extract the application and companion third-party source archives into the same directory as described in the release instructions.
